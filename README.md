# EDU Admin

Next.js admin application for managing educational courses and blocks.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features

- Load and edit course JSON files
- Tree view of Course > Lectures > Steps
- Edit course metadata, lectures, steps, and answers
- Export modified JSON

## Demo Files

Sample JSON files are in the `demo/` folder:
- `Course 79 Export Format.json` - Full course with lectures
- `EDU Block Design.json` - Simple block format
- `PedF Block Definition v3.json` - Advanced block schema with AI support
